# Teste tecnico virtual market
Esta pagina foi desenvolvida para o teste tecnico da virtual market

## Tecnologias usadas
- **PHP**: Usado nos modelos e nos controllers
- **MySQL**: Usado para armazenar os dados
- **SQL**: Utilizado na criacao das tabelas do banco de dados
- **AJAX**: Para enviar e receber requisicoes
- **HTML**: Estrutura dos templates(paginas)
- **CSS**: Visual dos templates(paginas)

### Como rodar windows

1. Clone o repositorio:
```bash
    git clone https://github.com/kauansr/Virtualteste.git
```

2. Copie e cole o SQL que esta na pasta sistema-comercial/sql no mysql para criar as tabelas.

3. Siga as instrucoes:
```bash
cd sistema-comercial

coloque suas credenciais do MySQL em database.php para conectar com o banco de dados

escolha uma porta para rodar o php e rode: php -S localhost:porta usando a porta que voce escolheu

acesse pelo navegador usando: localhost:porta
```

Lembre-se de que voce precisa ter o PHP e o MySQL na sua maquina.
